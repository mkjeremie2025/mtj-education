🖥️ Informatique générale

  • Matériel et logiciels
  • Fichiers et dossiers
  • Systèmes d'exploitation
  • Internet

🌐 Développement Web

Apprends progressivement à construire un site web.

  • HTML
  • CSS
  • JavaScript
  • Création de pages web

💻 Programmation

Comprends la logique utilisée pour donner des instructions à un ordinateur.

  • Variables
  • Conditions
  • Boucles
  • Fonctions

  • Utiliser des mots de passe solides
  • Protéger ses informations personnelles
  • Reconnaître les arnaques en ligne
